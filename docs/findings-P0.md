## P0-1: Twilio US ローカル番号の取得条件 → **Yes**

日本在住個人でも本人確認・住所証明（Regulatory Bundle）なしで即日購入・即日利用開始できる。US はBundle必須国リストに含まれていない。

**ただしこの根拠は消極的確認**: 「USがBundle必須国リストに載っていない」ことの確認であって、「日本在住個人が取得できる」と明示した一次情報は見つけていない。実際にConsoleで購入するまで確定ではない前提で進めること。

- US ローカル番号 月額 **$1.15**、着信 **$0.0085/分**
- 不明点: 日本の携帯からUSへ発信する側（自分のiPhone）の国際通話料はキャリア依存でTwilio外。docomo/au/SoftBankの料金表を別途確認する必要あり

### Toll-Free の検討結果（2026-08-20 追記）→ **採用しない。Localのまま**

保留にしていた「Voice専用ならToll-Free検証が不要か」は **不要で確定**。Toll-Free verificationはSMS/メッセージング固有の要件で、音声のみの利用では対象外（出典: Twilio公式ドキュメント）。

ただし**別の理由でToll-Freeは不採用**とする。

- **US Toll-Free（800/888/877等）は日本から確実には掛からない**。無料かつ到達可能なのはNANP圏内（米国・カナダ等）に限られ、国外発信は不通か、通っても国際料金がかかる。国際発信自体をブロックしている番号も多い
- **Toll-Freeの利点「掛ける側が無料」は国外発信では消える**ため、月額と分単価が上がるだけで見返りがない
- コスト差: 月額 $2.15 vs $1.15、着信 $0.0220/分 vs $0.0085/分。5分通話1回で約10円差、50回で約500円差と小さく、判断材料にはならない

**Toll-Freeが有効なのは、デモを見せる相手が米国・カナダにいる場合のみ。** 日本の相手に自由に掛けてもらう構成が必要になった場合の本筋は050番号（P2-9。書類・審査が必要）。

出典: [Programmable Voice Pricing US](https://www.twilio.com/en-us/voice/pricing/us) / [Toll-free verification onboarding](https://www.twilio.com/docs/messaging/compliance/toll-free/console-onboarding)（いずれも2026-08-20確認）

## P0-2: Twilioトライアル制限 → **有料化必須、金額は不明瞭**

想定より厳しい事実が出た。トライアルのままでは**`<Stream>` verb自体がブロックされ、Media Streams構成（design.mdの推奨案B）が技術的に動かない**。アナウンスが入る程度の話ではない。

- 有料化の最低入金額はTwilio公式一次情報では確認できず（二次情報で「$20目安」）。Console上で実際に試すのが最速
- 日本発行カードは基本通るが、AVS不一致や不正検知で稀に弾かれる
- **要対応**: 番号取得の前に、まずアカウントを有料化する

### 実機で判明した訂正（2026-08-20追記）→ **`<Stream>`はトライアルのままでも動いた**

上記の「トライアルでは`<Stream>` verb自体がブロックされる」という結論は、**Twilio Voice SDK（ブラウザ）経由での実機テストで否定された**。トライアルアカウントのまま、TwiML AppのVoice Request URLを設定してブラウザから発信したところ、Media Streamsが確立し、OpenAI Realtime APIとの音声往復も成立した。

ただし**トライアル特有の英語警告アナウンスは残る**（こちらのTwiMLの`<Say>`より前に、Twilio側が挿入する「You have a trial account…」相当のメッセージが再生される）。実害はなく、デモの体裁としては気になる程度。今回は許容する判断とした。

**未確認のまま残る点**: 今回検証できたのはVoice SDK（Client-to-TwiML）経由のみ。**PSTN番号への着信でも同様に`<Stream>`が動くかは未検証**。元の調査がPSTN経由を指していた可能性があり、発信経路によってトライアル制限の適用範囲が異なる可能性もゼロではない。番号を取得して実際に電話をかける段（Phase 5）で改めて確認すること。

## P0-3: OpenAI Realtime API 現行仕様 → **電話帯域は Yes、SIP直収は GA**

design.md執筆時の前提（AIアシスタントの知識、2026年5月時点）から更新が必要な点あり。

- 現行推奨モデルは **`gpt-realtime-2.1`**（2026-07-06リリース、割り込み挙動が改善版）。mini版もあり
- 音声フォーマットは **GA APIでは `session.audio.input.format` にネストして `audio/pcmu` / `audio/pcma` を指定する形に変更**されている。旧beta版のフラットな `"g711_ulaw"` 指定は通らない → **design.mdの実装イメージはこの新スキーマに合わせて修正が必要**
- **SIP直収（sip:{project_id}@sip.api.openai.com）は2025-08-28にGA化済み**。design.mdでは「案A」として次点扱いにしていたが、廃止でもベータでもなく正式機能。ただし今回はポートフォリオとして中身が見える案Bを優先する方針は変えなくてよい（可視性・デバッグ容易性の判断根拠は仕様GA/betaと無関係のため）
- 割り込みイベント名 `input_audio_buffer.speech_started` は現行も同名。VAD設定は `session.audio.input.turn_detection` にネスト。`semantic_vad`（意味論ベースの割り込み判定）という新モードも追加されている → 割り込み精度を上げたい場合はこちらを検討

## P0-4: コスト試算 → **50回テストで約3,000円（mini なら約1,400円）**

- 5分通話1回: 約56円（OpenAI音声トークン約46円＋Twilio通話・Streams約10円）
- 50回テスト: 約2,990円（flagship）/ 約1,415円（mini）＋番号月額$1.15
- Hard Spend Limitで上限は設定可能（即時反映ではなく多少超過しうる点は留意）

### 発信側の国際通話料（2026-08-20 追記）→ **ここがコストの主役だった**

「キャリア依存で算出不可」としていた項目が確定し、**既存試算を覆す規模**であることが判明した。

日本の携帯からUS本土への通話料:

| キャリア | 料金 | 分換算 |
|---|---|---|
| au | 39円/30秒 | **78円/分** |
| docomo WORLD CALL | 34円/30秒（昼）/ 31円（夜） | **68円/分** / 62円/分 |

50回 × 5分 = 250分での発信側負担は **au 19,500円 / docomo 17,000円**。Twilio+OpenAIの約3,000円と合わせると総額約22,000円で、**85%以上が発信側の携帯料金**になる。

**回避策（テスト段階はVoIP経由を推奨）**

| 方法 | 250分あたり | 備考 |
|---|---|---|
| iPhoneから直接 | 17,000〜19,500円 | 本番と同じ経路。録画用 |
| Twilioから折り返す | 約6,900円 | JP携帯宛 $0.1850/分。`<Connect><Stream>`は発信側でも動作する |
| **Twilio Voice SDK（ブラウザ）** | **約150円** | **$0.0040/分**。下記参照 |
| au国際通話定額 | 月980円程度 | 15分×60回。**未確認**（公式ページ404。auユーザーなら要確認） |
| ~~Skype Credit~~ | — | **2025-05-05にサービス終了。使えない** |
| ~~LINE Out~~ | — | **2023-05-31にサービス終了。使えない** |

**方針**: Phase 1〜4の反復テストは **Twilio Voice SDK（ブラウザ）** から発信する。同じTwiMLアプリを経由するため経路が本番と同一で、Media Streamsに繋がり音声もμ-law 8kHzに落ちる。割り込み処理も同条件で発火するため検証の忠実度は十分。国際通話が一切発生しない。

必要な準備: Twilio ConsoleでTwiML Appを作成 / アクセストークン発行エンドポイント / Voice JS SDKを読み込むHTMLページ（合計1時間程度）。

Phase 5の最終確認と録画のみ、実機のiPhoneからPSTNで行う（電話×AIというデモの趣旨上、ヒーロー素材は実通話であるべきため）。

**転用案**: このブラウザクライアントはそのまま「試せるデモ」にできる。国際電話も050も不要で誰でも触れる。ただし公開すると着信数だけOpenAI従量課金が発生する（1通話約56円）ため、録画を主役にし、ライブ版は限定公開かレート制限付きとする。

出典: [au 国際電話 アメリカ](https://www.au.com/mobile/service/global/call/charge/america/) / [docomo WORLD CALL](https://www.docomo.ne.jp/service/world/worldcall/call/) / [Twilio Voice Pricing Japan](https://www.twilio.com/en-us/voice/pricing/jp)（いずれも2026-08-20確認）
